# 🌿 AI Smart Farming Assistant

An end-to-end plant disease detection and farming advisory system built with MobileNetV2 transfer learning, FastAPI, and Vanilla JS.

> Hackathon Prototype — detects crop disease from a leaf photo and returns organic + chemical treatment recommendations alongside a voice-enabled NLP chatbot.

---

## ✨ Features

- 🔬 **Disease Detection** — Upload a leaf image and get an instant prediction with confidence score
- 💊 **Treatment Recommendations** — Organic and chemical solutions for every detected disease
- 🤖 **NLP Farming Chatbot** — Ask questions about irrigation, fertilizer, pests, and more
- 🎙️ **Voice Input & TTS Reply** — Hands-free interaction via Web Speech API
- ⚡ **CPU-friendly** — Runs on `tensorflow-cpu`, no GPU required

---

## 🌱 Supported Crops & Diseases

| Crop   | Classes |
|--------|---------|
| Tomato | Early Blight, Late Blight, Leaf Mold, Healthy |

## 🚀 Quick Start

### 1. Clone the repo

```bash
git clone https://github.com/shaikinzamam/ai-smart-farming-assistant.git
cd ai-smart-farming-assistant
```

### 2. Install dependencies

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Prepare the dataset

```bash
# Requires Kaggle API key at ~/.kaggle/kaggle.json
python prepare_dataset.py
```

### 4. Train the model

```bash
python train.py                        # default: 10 epochs, batch 32
python train.py --epochs 15 --batch_size 16   # custom config
```

### 5. Start the backend

```bash
uvicorn backend.main:app --reload
# API available at http://localhost:8000
```

### 6. Open the frontend

Open `frontend/index.html` directly in your browser — no build step needed.

|--------|----------|-------------|

## 🧠 Model Architecture

- **Backbone:** MobileNetV2 (ImageNet pretrained, frozen in Phase 1)
- **Head:** GlobalAveragePooling2D → Dense(256) → Dropout(0.35) → Dense(128) → Dropout(0.25) → Softmax
- **Training:** Two-phase — head-only first, then top-30 backbone layers fine-tuned at 10× lower LR
- **Augmentation:** Rotation, zoom, brightness shift, horizontal flip, shear
- **Confidence threshold:** 50% — low-confidence results surface a "retake photo" message
